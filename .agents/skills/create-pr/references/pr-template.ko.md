# 한국어 PR 템플릿

제목과 본문을 한국어로 작성한다. 저장소의 제목 규칙이 있으면 보존한다. 구체적인 문제와 변경 후 동작을 먼저 설명한다. 변경 규모에 맞게 분량을 조절하고 유용한 정보가 없는 선택 항목은 생략한다. 제출 전 아래 안내문을 확인된 사실로 교체한다.

```markdown
## 요약

해결하려는 문제와 변경 후 동작을 한두 문장으로 설명한다.

## 변경사항

- 검토자가 해결 방법을 이해하는 데 필요한 변경을 설명한다.

## 검증

- 실제로 실행한 검사와 결과를 작성한다.
- 관련 검사를 실행하지 않았다면 필요한 경우 그 이유를 작성한다.

## 관련 이슈

확인된 관련 이슈를 연결한다. 이 PR이 이슈를 해결하는 경우에만 종료 키워드를 사용한다.

## 스크린샷

시각적 변경을 이해하는 데 도움이 된다면 확보된 변경 전후 화면을 첨부한다.

## 위험 및 후속 작업

해당하는 경우 주요 제약, 호환성 영향, 후속 작업을 설명한다.
```

저장소가 다른 구조를 요구하지 않으면 `요약`과 `검증`을 최소 본문으로 사용한다. 요약만으로 설명이 부족할 때 `변경사항`을 유지한다. 나머지는 관련이 있을 때만 포함한다. 실행 근거 없이 테스트 통과를 주장하거나 이슈 링크·스크린샷을 만들어내지 않는다.
